## 📌 Proyectos destacados

A medida que avanzo, mis proyectos van sumando complejidad y buenas prácticas de ingeniería de software:

### 🍎 [django-react-apples](https://github.com/luccamaidana/django-react-apples)
App full-stack con catálogo de manzanas: API en **Django** + frontend en **React/Vite** con animaciones (Framer Motion). Primer proyecto donde integré backend y frontend de forma completa.
`Python` `Django` `React` `Vite` `Framer Motion`

### 📦 [confirmacion-transaccional-despacho-django](https://github.com/luccamaidana/confirmacion-transaccional-despacho-django)
API en Django para confirmar despachos de última milla de forma **transaccional**: un servicio de dominio orquesta el cambio de estado del envío y la creación del movimiento operativo como una unidad atómica. Foco en integridad de datos y lógica de negocio.
`Python` `Django` `Domain Services`

### 🚚 [seguimiento-envios-django](https://github.com/luccamaidana/seguimiento-envios-django)
Sistema de seguimiento de envíos desarrollado en Django.
`Python` `Django`

### 📋 [orden-retiro-django](https://github.com/luccamaidana/orden-retiro-django)
Alta de órdenes de retiro para operadores logísticos, con vistas basadas en función, formularios HTML y persistencia en base de datos.
`Python` `Django`

### 🧮 [calculator](https://github.com/luccamaidana/calculator)
Proyecto final del curso Foundations: una calculadora funcional en JavaScript puro. Uno de mis primeros pasos en el desarrollo web.
`JavaScript`
